# QuarborHIDFilterUserDriver 源码说明

## 1. 驱动定位

QuarborHIDFilterUserDriver 是一个运行在 UMDF 2.33 宿主中的 Windows HID 用户态过滤驱动，目标是被手动绑定到指定的 HID Keyboard Collection。

当前安装模型具有以下特点：

- INF 使用私有硬件 ID `QUARBOR\\HidKeyboardManualBinding`，不会自动匹配所有键盘。
- 安装时保留系统的 `keyboard.inf` / `kbdhid` 功能驱动，并通过 `WUDFRD_LowerFilter` 挂载本过滤器。
- 驱动项目目标为 Desktop、x64、UMDF 2.33。
- 驱动不要求普通客户端直接打开键盘设备，而是通过每个设备独立的本地命名管道通信。
- 物理 HID 报告由驱动自己的下层读取请求采集；用户态客户端可以订阅原始报告，也可以通过管道请求注入报告或语义按键。

## 2. 实际输入行为

本驱动不是一个“只旁路观察、不影响正常输入”的透明过滤器。当前实现将上层 `READ` 请求放入手动队列，并不会把这些请求继续转发给下层 HID 设备。

因此，设备绑定该过滤器后：

1. `HidReader` 从过滤器下方独立打开 HID Collection，持续读取物理报告。
2. 物理报告发布到命名管道，供客户端观察。
3. `InputQueue` 只把通过命名管道注入的报告交付给上层 `kbdhid` READ。
4. 如果没有客户端注入报告，上层等待中的 READ 不会收到物理报告。
5. 客户端断开时，驱动清空待交付注入报告，并为已经交付过的 Report ID 安排中性报告，避免残留按键状态。
